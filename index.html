What do these words mean?
Job setup
Behind the scenes this is called a "job requirement package" — the job details, scoring weights, fairness rules, and check-sensitivity settings, bundled and versioned together so every candidate is measured the same way.
"Should stay the same" / "Can change — but only here" / "Should resist the trick"
The technical terms for these are, respectively: invariant, rubric-consistent, and robust.
Personal contact details
Also called PII — personally identifiable information — things like email addresses, phone numbers, and street addresses.
Hidden fake instruction
Also called a prompt injection — text embedded in a document that tries to manipulate an AI system into ignoring its real instructions.
Move forward / Don't move forward / Have a person review / Can't give a reliable answer yet
Internally labeled ADVANCE, DO_NOT_ADVANCE, HUMAN_REVIEW, and UNRELIABLE_ABSTAIN.
Score change
Also called a delta (Δ) — the technical term for how much a score moved between two versions of the same resume.
PDF text extraction
Uploading a PDF here uses a general-purpose PDF reader (PDF.js), not a commercial resume parser. It pulls out raw text but doesn't identify fields like name, work history, or education the way a dedicated resume-parsing service would, and can jumble multi-column layouts. This is an MVP shortcut — a production version should use a commercial resume-parsing API instead.
